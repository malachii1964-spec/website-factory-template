# Capability Pack Catalog

Packs extend the constitutional core. They are loaded only when their trigger is satisfied and cannot weaken truth, authority, accessibility, security, evidence, or release rules.

| Pack | Trigger | Primary deliverables | Reject when |
|---|---|---|---|
| Immersive 3D | spatial/narrative/product value is load-bearing | scene contract, asset budget, fallback, frame/memory evidence | decoration alone or no fallback budget |
| Maps & Logistics | geography/routes/status changes user decisions | map/data/provider architecture, accessible equivalent, privacy/cost | decorative map or fake-live routes |
| Adaptive UX | user-controlled density/energy/first-win modes improve access | preference model, progressive disclosure, low-energy path | covert profiling or pseudo-neuroscience |
| AI Features | probabilistic generation/retrieval adds unique value | model/tool contract, provenance, evals, privacy, deterministic fallback | rules/search is safer and sufficient |
| Cannabis Compliance | cannabis education/cultivation/wellness/commerce content | source/claim/jurisdiction/age and safety gates | never omit on a cannabis project |
| Remote Rendering | required fidelity cannot be delivered locally | streaming architecture, capacity/cost/latency/security/fallback | local tier is sufficient or budget unaccepted |
| Commerce | catalog, price, cart, subscription, checkout, payments | product/order model, provider/webhooks, taxes/refunds, tests | no transactional job |
| Content Operations | ongoing structured publishing | content model, roles, workflow, preview/versioning, SEO | one-off static content |
| Domain, DNS, Email & Deployment | a domain, DNS zone, inbound/outbound mail, hosting, or production cutover is in scope | ownership inventory, DNS snapshot, collision plan, provider records, authentication proof, rollback, health checks | no authority, no rollback snapshot, exposed credential, or unresolved ownership |

Every selected pack records why it is active, who owns it, cost/failure mode, and exit evidence in the Project Lock.
