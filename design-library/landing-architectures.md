# Landing architectures

Learned from high-end landing explorations (including a courier set used **only as layout reference**). This file is not a product, domain, phone number, or brand.

Factory interview: pick **one architecture** for the first screen. Do not stack three.

Pair with `styles.md` (vibe) + `marks.md` (mark) + `immersive-3d.md` (if a canvas exists) + VisualDNA.

## What “high-end” meant in those boards

Not more effects. These repeats showed up in the good frames:

- One job visible before the fold
- One signature object or typographic move
- Dark or light field used as *mass*, not a theme pack
- Type that would still work if you stripped color
- CTA as a designed object, not a default button
- Empty space doing structure
- Motion that finishes, then stops
- Legal/secondary line present but not the hero

## Architecture cards (tenant-agnostic)

Use the code in VisualDNA notes: `landing_arch: KA` etc.

| Code | Architecture | First screen | Steal this | Kill if |
|---|---|---|---|---|
| KA | Kinetic split type | Two huge word stacks left/right, a thin connector | Type *is* the signature | Every line animates; festival poster |
| TB | Task-tile chooser | 4 large job tiles, not a product catalog | Decision UI as design | Clone of a delivery-app menu |
| ST | Object field | Physical tokens (stickers, stamps, cards) on a material photo | Subject’s vernacular objects | Sticker vomit |
| FZ | Frame / bezel | UI sits inside a designed device or cabinet | World-as-chrome | Theme-park overlay hiding type |
| WP | Poster stack | Sections are printed sheets, not cards-on-gray | Editorial scale | Fake paper that hides the CTA |
| LN | Single line geography | One path/line *is* the service area or process | Map without a Google embed | 12 neon beams |
| DB | Honest dashboard | Panels only if numbers are real or clearly static | Operational prestige | Fake live fleet / fake users |
| GL | Controlled glitch | One stable object; the rest settles in <500ms | Energy then calm | Permanent RGB split |
| DR | Drop graphic | One oversized mark, sparse copy | Campaign site | Box-logo parody |
| SP | Spatial chamber | Enter a space (VI catalog) | Depth | Canvas as LCP |

## How the Factory uses this

1. Name the tenant job.
2. Offer three cards from **different rows**.
3. Human picks one architecture + one `styles.md` direction.
4. If SP: attach 3D performance contract before BUILD.
5. Twin-tab against three live sites in the *same category*, not against the reference boards.

## Explicitly not stored here

No domain, no phone, no town list, no courier slogan, no farm SNAP copy. Those belong in a tenant brief when a site is actually being built.
