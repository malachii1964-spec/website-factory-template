## How a Factory interview uses this

1. Name tenant + job.
2. Offer **three numbered styles from different sections**.
3. Human picks one. Record `catalog_id` in VisualDNA notes.
4. Generate three concepts *inside that one style*. Kill list from `marks.md` + `design.md`.
5. If the pick is 51–60, attach `immersive-3d.md` performance contract before BUILD.
